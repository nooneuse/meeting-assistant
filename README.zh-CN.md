# Meeting Assistant · 会议助手

[English](README.md) · [简体中文](README.zh-CN.md)

开源 Android 会议助手，将实时听写与幻灯片、文档中的文字结合，在讨论中提供答案和建议。

**Android 8.0+ · 自备 API Key · MIT**

## 功能

- **手动与自动模式**：停止聆听后分析，或随讨论进展持续更新答案。
- **音频输入**：选择机身、USB、支持的蓝牙麦克风或可用的采集卡音频。
- **图像输入**：从手机相机或 USB 视频来源抓拍，识别文字与布局，结合听写分析。
- **议题与议题集**：用目录整理讨论，恢复已有议题，各议题的上下文独立保存。
- **回答偏好**：保存并切换回答方向、语言和风格等指令。
- **键盘控制**：自定义蓝牙键盘快捷键，控制聆听、抓拍、滚动与议题导航。
- **自适应界面**：支持横屏、竖屏和折叠屏，跟随系统明暗模式与动态配色，提供简体中文和英文界面。

## 快速使用

1. 打开 **☰ → 设置 → 模型连接**，填写语音识别和文字分析服务的地址、模型与 API Key；使用图像输入时再配置图像识别服务。
2. 在左侧边栏新建议题或继续已有议题，用议题集整理相关讨论。
3. 在设置的**回答偏好**中保存指令，点击主界面的偏好名称快速切换。
4. 点击**开始听**，再点击**停止听**进行分析；需要自动分段并持续更新答案时，先开启 **Auto**。
5. 分析幻灯片或文档时，点击右上角的**输入来源**，开启视频并选择来源。在**图像输入设置**中预览画面，之后通过相机按钮抓拍并分析。

灯泡控制屏幕常亮，原文按钮显示或隐藏听写内容，复制图标可复制结果。音频来源也可在**输入来源**中选择。

### 键盘快捷键

先在 Android 系统中配对键盘，再到**设置 → 外接按键**中自定义绑定。

| 操作 | 默认按键 |
| --- | --- |
| 开始 / 停止聆听 | 空格 |
| 答案向上 / 向下滚动 | ↑ / ↓ |
| 原文向上 / 向下滚动 | Page Up / Page Down |
| 不使用回答偏好 | 0 |
| 切换屏幕常亮 | L |

Auto、图像抓拍、新建议题、议题与议题集切换、原文显隐等操作也可绑定按键。

## 工作原理

语音实时转为听写原文，抓拍图像提取文字和布局信息。文字模型结合这些输入、当前议题上下文与回答偏好，生成或修正答案。自动模式下，文字分析与音频采集独立运行，分析期间继续收音。

每个议题维护独立的历史与上下文。随着讨论增长，上下文管理会选择和整理相关信息，控制模型输入规模。议题集负责组织议题，不共享各议题的上下文。

应用通过服务适配器连接模型接口：

| 用途 | 支持的接口 |
| --- | --- |
| 语音识别 | 阿里云 Fun-ASR Realtime |
| 文字分析 | OpenAI 兼容的 Chat Completions，包括托管 DeepSeek |
| 图像识别 | Qwen3.5-OCR 或兼容的结构化视觉输出 |

音频和图像发送至配置的识别服务，相关文字发送至文字分析服务。议题记录与 API Key 在设备上加密保存，不保存录音文件，不提供云同步。聆听在应用前台运行。模型服务费用与数据政策由所选供应商决定，重要回答请结合原始资料核对。

## 构建与安装

需要 **JDK 21**、**Android SDK 36** 和 **Build Tools 36.0.0**。使用 Android Studio 打开项目，或设置 `ANDROID_HOME` 后执行：

```sh
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Windows 使用 `gradlew.bat`。开发与测试命令见[贡献指南](CONTRIBUTING.md)。
