UVCAndroid 1.0.13 / native video dependencies

UVCAndroid by shiyinghan, with UVCCamera by saki. Apache-2.0.
Official source tag: https://github.com/shiyinghan/UVCAndroid/tree/1.0.13
Source commit: 6018c7f20238832929cf61427427bb7828056260
The Maven artifact is used without modifying its binaries. Only the low-level
video API is called. Image/audio recording helpers and storage permissions
are not used. No native library is statically linked into our Java app code.
