# 本地化维护说明

## 语言规则

系统首选语言为简体中文时显示简体中文，否则显示英文。`UiLocale.choose` 接受 Hans、无脚本的 zh / zh-CN / zh-SG 等；Hant、zh-TW、zh-HK、zh-MO 以及非中文语言回退为 en。只看首选语言，不能使用资源匹配后的“最接近已支持语言”覆盖用户语言顺序。

Android 13+ 使用 [LocaleManager.getSystemLocales](https://developer.android.com/reference/android/app/LocaleManager#getSystemLocales()) 读取系统语言，忽略应用单独语言覆盖；Android 8–12 使用系统 Resources。Activity 每次创建时建立局部配置上下文，设置资源语言及布局方向，不修改系统语言或 Java 全局 Locale。语言变更继续使用 Android 的 Activity 重建，应用会话由 Application 持有。

英文是默认资源，简体中文位于 `values-b+zh+Hans`。App Bundle 禁用语言拆分，开源 APK / Bundle 都带两套资源，无需下载语言包。本版没有应用内语言选项。

## 可翻译内容与用户数据

- 界面文案、对话框、字段标签 / 提示、无障碍名称、Toast 使用命名字符串资源。
- 包含名称、序号的文案使用带位置的格式参数；不要拼接需翻译的句子。保留类型与顺序编号，例如 `%1$s`、`%2$d`。
- 状态、存储和服务错误通过 `LocalizedMessages` 的明确目录转换，仅用于应用自有提示。旧存档中的固定中文状态也可在英文界面正确显示。未知内部中文错误使用通用英文提示，不把原始供应商响应暴露到界面。
- `values/notices.xml` 声明可呈现的 core 消息；中文模板匹配的是既有业务消息，英文模板是展示结果。新增 core 提示时同步更新此目录及两种资源，并补充参数化 / 脱敏错误测试。
- 原文、模型答案、自定义会议名和已保存偏好不是界面资源，禁止送入固定消息转换器或使用整段字符串替换翻译。新的原文归档保留段落及定稿属性，标记按资源生成；旧归档无法区分原始文字和历史标记时保留原文。
- 默认会议名称使用创建时间生成本地化名称，用户重命名或从问题自动摘取的标题保持原样。两个预置偏好的名称和提示词仅首次安装按界面语言初始化，保存后与用户创建的偏好遵循相同规则：切换系统语言不更改名称或提示词，不重新播种、不覆盖编辑、不复活已删除配置。中文环境首次安装得到「算法讨论」「金融会议」，英文环境首次安装得到「Algorithm discussion」「Finance meeting」；之后均保持保存时的内容。
- 默认文字提示词遵循问题所用语言，用户明确指定回答语言时优先遵从；界面语言不改写听写或强制翻译会议内容。

## 状态提示

Auto / 常亮切换使用系统 Toast，与会议删除提示风格一致。开关提示为短时长，新提示取消旧提示，退出页面 / 前台时取消。不得重新加入按钮旁 PopupWindow 定位逻辑。

## 验证

电脑测试覆盖简体 / 繁体 / 英语 / 法语回退、包含中文次选项的语言顺序、资源完整性、历史状态和参数化服务错误、用户数据不被替换、语言切换保留会议、英语三种尺寸布局和中文既有回归。

```sh
./gradlew :core:test :app:testDebugUnitTest :app:assembleDebug :app:assembleDebugAndroidTest :app:lintDebug
```

真机检查系统语言切换及恢复、两种语言的 Toast、设置页和侧栏、当前任务不被语言切换重新启动。测试前保存原系统语言与旋转设置，结束后恢复，并关闭开发者「充电时不休眠」。不需要真实录音或模型请求。
